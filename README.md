# ☕ Созвонимся? | Interactive Online Date Invitation ✨

Интерактивное веб-приложение для планирования идеального онлайн-вечера и романтического созвона. Разработано в формате шаг-за-шагом с анимированными гифками, гибким выбором активностей, музыкальными вайбами и секретными интригами.

Создано специально к памятной дате — **1 месяц общения** 💖.

---

### ✨ Главные возможности и фичи

- **🎯 Интерактивный планировщик вечера:** 
  - **🎬 Фильмы / Аниме:** Рекомендации (`1+1`, `Унесённые призраками`), выбор настроения (Комедия, Триллер) и **поисковая строка** для ввода её любимого кино/аниме.
  - **🎮 Онлайн-игры:** Кооперативные рекомендации (`It Takes Two`, `Gartic Phone`, `GeoGuessr`, `Skribbl.io`, `Codenames`) + поле для своего варианта.
  - **🎵 Музыкальные вайбы & Поиск трека:** Выбор атмосферы (*Ночной Chill*, *Инди-рок*, *Pop/R&B*, *Акустика*) и секретное поле ввода для её любимой песни/исполнителя, чтобы устроить сюрприз на созвоне!
  - **☕ Разговоры за чаем:** Уютный формат для неспешной беседы.

- **🎲 Рулетка судьбы ("Довериться судьбе"):** Анимированный рандомайзер с эффектом прокрутки и праздничным салютом из конфетти.
- **🎟️ Игровые купоны на вечер:** Возможность выбрать виртуальный купон (*Право вето на выбор активности*, *Секретный кадр со смешным лицом* и др.).
- **💌 3D-конверт с секретом:** Анимированный 3D-конверт с сургучной печатью-сердечком, вылетающими эффектами и праздничной запиской в честь 1 месяца вместе.
- **✈️ Персональный Boarding Pass:** Посадочный билет на созвон с автоматической подстановкой пассажира, выбранного мессенджера и времени.
- **🎨 Динамическая атмосфера:** 
  - Автоматическая смена фоновых GIF при переходе по разделам (`lofi.gif`, `cinema.gif`, `gaming.gif`, `cat_vinil.gif`, `cip.gif`).
  - Переключатель цветовых тем (Классическая, Звёздная, Неоновая) и встроенный Lofi-плеер.

- **📱 Умная отправка ответа:**
  - **Telegram (`@Ваш Ник Телеграмм`)** — авто-переход со сформированным текстом ответа в один клик.
  - **Discord (ID: `Ваше айди Discord`)** — авто-копирование итогового сообщения в буфер обмена и переход в профиль.
  - **Google Календарь** — кнопка быстрой генерации события со всеми выбранными деталями вечера.
